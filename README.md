# Мои конспекты

Статический сайт без зависимостей. Кидаешь HTML и PDF в `content/`, пушишь, Vercel сам пересобирает.

## Как добавить конспект

```
content/
  math/
    01-limits.html      <- заголовок берётся из <title>
    02-series.pdf       <- для PDF заголовок = имя файла
  mechanics/
    01-inertia.html
    assets/             <- картинки и стили для конспектов (в список не попадают)
```

- Папка в `content/` = предмет. Новая папка = новый раздел, ничего настраивать не надо.
- Цифры в начале имени (`01-`, `02-`) задают порядок и на сайте не показываются.
- Красивое имя предмета задаётся в `site.config.json` (`"math": "Матан"`). Без записи будет имя папки.
- Папки и файлы, которые начинаются с `.` или `_`, сайт игнорирует (удобно для черновиков).

```bash
git add . && git commit -m "новый конспект" && git push
```

## Локальная проверка

```bash
npm run build      # собирает dist/
npm run preview    # собирает и открывает на localhost
```

## Vercel

Всё уже прописано в `vercel.json` (build: `npm run build`, output: `dist`). Если Vercel спросит про Framework Preset, выбирай **Other**.

## Закрыть сайт от посторонних

- В Vercel: Settings → Deployment Protection (доступность зависит от тарифа).
- Поисковики и так отшиты: в `vercel.json` стоит заголовок `X-Robots-Tag: noindex`. Хочешь, чтобы гуглился, удали блок `headers`.
