2Реакция на 1 Нм³ CH₄

1 CH₄ + 2 O₂ + 7,52 N₂ → 1 CO₂ + 2 H₂O + 7,52 N₂

CH₄ 100 %. 1 кмоль = 22,41 Нм³ (0 °C, 1013,25 мбар), поэтому коэффициенты = объёмы. 7,52 = 2·79/21.

3Теоретические величины

L₀  = 2 + 7,52      = 9,52  Нм³/Нм³
V₀d = 1 + 7,52      = 8,52  Нм³/Нм³
V₀w = 1 + 7,52 + 2  = 10,52 Нм³/Нм³

4Коэффициент избытка воздуха n !!

точно:      n = 1 + (V₀d/L₀)·O₂/(21 − O₂)
              = 1 + (8,52/9,52)·(13,5/7,5)
              = 1 + 0,895·1,8 = 2,61

упрощённо:  n = 21/(21 − 13,5) = 2,8   (= λ с TESTO)

В отчёт идёт точная формула (обведена на доске). Дальше считаем с n = 2,61.

5Реальный воздух и дым

(n − 1)·L₀ = 1,61·9,52 = 15,34 Нм³   ← лишний воздух

L   = n·L₀            = 2,61·9,52     = 24,86 Нм³/Нм³
V_d = V₀d + (n−1)·L₀  = 8,52 + 15,34  = 23,86 Нм³/Нм³
V_w = V₀w + (n−1)·L₀  = 10,52 + 15,34 = 25,86 Нм³/Нм³

6Сколько газа сгорело (в Нм³)

V_g   = 1789,172 − 1788,905 = 0,267 м³   (12:35 → 12:45, 10 мин)

V_GN  = V_g · p_газ/1013,25 · 273,15/(273,15 + t_газ)
      = 0,267 · 1058/1013,25 · 273,15/294,45
      = 0,267 · 1,0442 · 0,9277 = 0,2586 Нм³

1058 мбар в столбце «Gas pressure» — абсолютное давление газа, так и подставлено на доске (у препода вышло 0,258).

7КПД прямым методом

G = 527,401 − 527,326 = 0,075 м³ воды

η = G·(t₂ − t₁)·c_v / (F_é·V_GN) · 100%
  = 0,075·(58 − 38)·4186,8 / (34000·0,2586) · 100%
  = 6280 кДж / 8793 кДж · 100% = 71,4 %

Мощность газа: 8793 кДж / 600 с ≈ 14,7 кВт. В воду ушло 6280 кДж / 600 с ≈ 10,5 кВт.

8Потери с уходящими газами Qf

Q_f = V_w·(t_f − t_air)·c_f / F_é · 100%
    = 25,86·(122,7 − 42,5)·1,35 / 34000 · 100%
    = 25,86·80,2·1,35 / 34000 · 100% = 8,2 %

9КПД косвенным методом

Q_CO ≈ 8·10⁻⁶·23,86·12640/34000·100% ≈ 0,01 %   (8 ppm — ничтожно)
Q_s  ≈ 2 %   (оценка, не измерялось)

η = 100 − Q_f − Q_CO − Q_s = 100 − 8,2 − 0,01 − 2 = 89,8 %
без Q_s:  100 − 8,2 = 91,8 %   ≈ TESTO 92,2 % ✔

!Где доска расходится с формулой
