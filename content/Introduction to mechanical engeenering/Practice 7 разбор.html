Practice 7 разбор

Ща разложим эту хуйню по полочкам. На самом деле там одна идея и пять формул, всё остальное это подстановка. Внутри: все символы по одному, решения 7.1–7.3 с каждым шагом, пять новых задач с ответами под спойлером и чит-шит в конце.

Символы7.17.27.35 задачЧит-шит
Одна идея на всё занятие. Машина берёт мощность на входе, часть отдаёт в дело, остальное греет воздух.
  • Вход = полезное + потери: Pin = Puseful + Ploss
  • КПД: η = Puseful / Pin (сколько из входа дошло до дела)
  • Нагрузка: x = Puseful / Pn (какую долю от паспортной мощности выжимаем)
  • Потери: Ploss = Pc + xn·Pv1 (часть не зависит от нагрузки, часть растёт с ней)

Все символы

В листе нет никакой θ (теты). Есть η, это «эта», похожа на n с хвостом вниз. Дальше идут все буквы, которые встречаются в условиях и формулах.

ηэта
КПД. Доля входной мощности, которая стала полезной. От 0 до 1 или в процентах: 0.64 = 64 %. Не бывает больше 1, иначе вечный двигатель.
xload factor
Коэффициент нагрузки. x = Puseful / Pn. x = 1 это полная паспортная нагрузка, x = 0.5 половина, x = 0 холостой ход.
Ppower
Мощность, в ваттах (W). 1 kW = 1000 W. Это скорость, с которой передаётся энергия.
Wwork
Работа или энергия, в джоулях (J) или kWh. W = P·t, если мощность постоянная. Не путай с единицей W (ватт), это другая хуйня.
ttime
Время. Если мощность в kW, а время в часах, получишь kWh. В 7.2 время в минутах, но в отношениях они сокращаются.
PinPinput
Входная мощность. Что машина забирает: из розетки у мотора, от мотора у редуктора. В редукторе её же обозначают с индексом 1.
PusefulPout
Полезная мощность на выходе. У редуктора это P2 = M2·ω2.
Ploss
Мощность потерь. Всё, что ушло в тепло, шум, трение: Pin − Puseful.
Pnnominal
Номинальная полезная мощность. Та, на которую машина рассчитана, написана на шильдике. При x = 1 полезная мощность равна ей.
Pcconstant
Постоянные потери. Есть всегда, даже без нагрузки: трение в подшипниках, перемагничивание железа мотора, вентилятор. Не зависят от x.
Pv1variable
Переменные потери при x = 1. Растут с нагрузкой, например нагрев обмоток током. Индекс 1 значит «при x = 1», при другом x они равны xn·Pv1.
nстепень
Показатель степени в xn. 1 для механики (шкивы), 2 для электрики (моторы), 3 для гидравлики (насосы, вентиляторы). Это число тебе дают или выбирают по типу машины.
n1, n2RPM
Обороты в минуту (revolutions per minute). Та же буква n, но это совсем другое. Если n стоит рядом с RPM, то это обороты, если в степени у x, то показатель.
ωомега
Угловая скорость в рад/с. Переводится из оборотов: ω = 2π·n / 60. Деление на 60 это минуты в секунды, 2π это один оборот в радианах.
πпи
3.14159. Один оборот = 2π радиан.
igear ratio
Передаточное отношение. i = ω1/ω2 = z2/z1. Показывает, во сколько раз выходной вал медленнее входного. i = 25 значит 25 оборотов червяка на один оборот колеса.
zteeth
Число зубьев. z1 у ведущей детали (у червяка это число заходов резьбы, там z1 = 1), z2 у ведомого колеса.
Mtorque
Крутящий момент, в Н·м (Nm). Связь с мощностью: P = M·ω.
1, 2индексы
В редукторе 1 = ведущая (driving, на входе), 2 = ведомая (driven, на выходе). В 7.2 и 7.3 индексы значат другое: режим работы или точка измерения, читай условие.
U, Iвольты, амперы
Напряжение и ток мотора. Электрическая мощность на входе Pin = U·I.
m, m0, k, gбалансир
m это масса на плече, m0 масса, которой уравновешивали на холостом ходу, k длина плеча (м), g = 9.81 м/с² ускорение свободного падения.
xopt
Нагрузка с максимальным КПД. Для n = 2 это √(Pc/Pv1), для n = 3 это ∛(Pc/(2Pv1)).
avg
Среднее за цикл: ηavg, xavg. Считается через энергии W, а не через мощности.

Exercise 7.1 · Червячная передача

Дано Червяк (z1 = 1) крутит колесо. Отношение моментов M2/M1 = 16, η = 64 %. Мотор крутит со скоростью n1 = 1440 RPM, момент на колесе M2 = 800 Nm.
  1. z2
  2. i
  3. мощность мотора

Главный трюк: связать КПД с моментами

Мощность вращения P = M·ω. КПД это выход делить на вход:

η = P2P1 = M2·ω2M1·ω1 = M2M1·ω2ω1 = M2/M1i

Потому что ω2/ω1 = 1/i. Отсюда M2/M1 = η·i. Идеальная передача (η = 1) увеличивает момент ровно во столько, во сколько уменьшает скорость. Реальная теряет часть.

  1. a) и b) Передаточное отношение i Из M2/M1 = η·i выражаем i:
    i = M2/M1η = 160.64 = 25
    Проценты в формулу идут как доли: 64 % = 0.64.
  2. a) Число зубьев колеса z2
    i = z2z1 ⇒ z2 = i·z1 = 25·1 = 25
  3. c) Угловая скорость мотора ω1 Мотор крутит червяк, а n1 дана в оборотах в минуту, поэтому переводим в рад/с:
    ω1 = 2π·n160 = 2π·144060 = 150.80 rad/s
  4. c) Момент на входе M1
    M1 = M216 = 80016 = 50 Nm
  5. c) Мощность мотора Мотор отдаёт червяку мощность P1 = M1·ω1:
    P1 = 50·150.80 = 7540 W = 7.54 kW
    Проверка другим путём. Выходная мощность P2 = M2·ω2 = 800·6.032 = 4825 W. Делим на КПД:
    P1 = P2η = 48250.64 = 7540 W ✓
    Совпало, значит всё верно. Потери в передаче: 2714 W, они уходят теплом в масло и корпус.
Ответ: z2 = 25, i = 25, мощность мотора ≈ 7.54 kW.

Exercise 7.2 · Мощность и КПД за цикл

Дано Цикл повторяется, длится T = 40 min. При обработке детали входная мощность Pin1 = 8 kW, КПД при полной нагрузке η1 = 79 %. Пока меняют заготовку (холостой ход), Pin2 = 1.3 kW.
  1. За какое время надо менять деталь, чтобы средний КПД был η = 75 %?
  2. Средняя нагрузка, если смена занимает 10 min.

Идея: бюджет на холостой ход

Среднее арифметическое КПД (79 % и 0 %) даст хуйню, потому что режимы длятся разное время. Берём формулу из листа ηavg = Wuseful/Winput. Полезную энергию даёт только рабочий ход. Значит, при ηavg = 75 % машине разрешено сожрать Wuseful/0.75. Сколько-то из этого уходит на сам рабочий ход, а остаток и есть бюджет, который можно спустить на холостой ход.

t1 это время работы, t2 время смены детали (мои обозначения, в листе их нет). Удобно считать всё на 1 минуту рабочего хода, тогда вместо энергий можно двигать мощности.

  1. Полезная мощность при работе Из η = Puseful/Pinput:
    Puseful1 = η1·Pin1 = 0.79·8 = 6.32 kW
  2. a) Сколько входной мощности разрешено на минуту работы Из ηavg = Wuseful/Winput: чтобы КПД был 75 %, на каждую минуту работы можно потратить
    Pallowed = Puseful1ηavg = 6.320.75 = 8.427 kW
  3. a) Бюджет на холостой ход Сам рабочий ход берёт 8 kW, остаток можно спустить на смену детали:
    ΔP = Pallowed − Pin1 = 8.427 − 8 = 0.427 kW
    Холостой ход жрёт 1.3 kW, значит на одну минуту работы можно позволить
    t2t1 = ΔPPin2 = 0.4271.3 = 0.3282 минуты холостого хода
  4. a) Раскидываем 40 минут цикла На каждую минуту работы приходится 0.3282 минуты смены, то есть одна «минута работы» на деле занимает 1 + 0.3282 минуты цикла:
    t1 = T1 + t2/t1 = 401 + 0.3282 = 30.12 min t2 = T − t1 = 40 − 30.12 = 9.88 min
    Смена детали должна занимать не дольше ≈ 9.9 min, иначе средний КПД упадёт ниже 75 %.
    Одной формулой: t2 = T·k1 + k, k = Puseful1/ηavg − Pin1Pin2
    Проверка по формуле из листа: Wuseful = 6.32·30.12 = 190.3 kW·min, Winput = 8·30.12 + 1.3·9.88 = 253.8 kW·min, ηavg = 75.0 % ✓
  5. b) Средняя нагрузка xavg = Wuseful/Wnominal. Пока машина работает, она на полной нагрузке, значит её номинальная полезная мощность Pn = 6.32 kW. Номинальная энергия за цикл это Pn·40 min.
    xavg = 6.32·306.32·40 = 3040 = 0.75
    Получилось просто t1/T: машина работает на полную 30 мин из 40. Средний КПД при этом 74.9 %, чуть меньше 75 %, потому что 10 мин чуть дольше предельных 9.9 мин. Всё сходится.
Ответ: a) смена детали ≤ 9.9 min, b) средняя нагрузка xavg = 0.75 (75 %).

Exercise 7.3 · Балансирный мотор

Дано n = 3000 RPM, Pn = 420 W. Масса на холостом ходу m0 = 0.02 kg, плечо k = 0.35 m. В первой точке m = 0.4 kg, U = 220 V, I = 2 A. Вторая точка: x2 = 0.5, η2 = 95 %.
  1. Нагрузка, КПД и потери в первой точке
  2. Параметры Pc и Pv1
  3. График потерь и КПД от x
  4. Нагрузка с максимальным КПД

Что это за установка

Статор мотора висит на подшипниках и может качаться. Когда ротор крутит нагрузку, статор стремится провернуться в обратную сторону с таким же моментом. Этот момент уравновешивают грузом m на рычаге длиной k. Значит по грузу видно момент мотора, а по моменту и скорости видно полезную мощность. Масса m0 это груз, который понадобился даже на холостом ходу (перекос и трение), его вычитаем.

Допущения: груз вычитается как (m − m0), и входная мощность Pin = U·I (cos φ в условии не дан, значит считаем 1). Если препод на лабе считает иначе, подставь его формулу, а ход решения останется тем же.

a) Первая точка измерения

  1. Момент мотора
    M = (m − m0)·g·k = (0.4 − 0.02)·9.81·0.35 = 1.3047 Nm
  2. Угловая скорость
    ω = 2π·300060 = 314.16 rad/s
  3. Полезная мощность
    Puseful = M·ω = 1.3047·314.16 = 409.9 W
  4. Коэффициент нагрузки
    x1 = PusefulPn = 409.9420 = 0.976
  5. Вход, КПД и потери
    Pin = U·I = 220·2 = 440 W η1 = 409.9440 = 93.2 % Ploss1 = 440 − 409.9 = 30.1 W

b) Параметры Pc и Pv1

Для электрической машины n = 2, значит Ploss = Pc + x²·Pv1. Неизвестных два, поэтому нужны две точки. Первая у нас есть, вторую вытащим из условия.

  1. Вторая точка
    Puseful2 = x2·Pn = 0.5·420 = 210 W Pin2 = Puseful2η2 = 2100.95 = 221.05 W Ploss2 = 221.05 − 210 = 11.05 W
  2. Система из двух уравнений
    Pc + 0.9525·Pv1 = 30.11 (точка 1) Pc + 0.25·Pv1 = 11.05 (точка 2)
  3. Вычитаем одно из другого, Pc исчезает
    (0.9525 − 0.25)·Pv1 = 30.11 − 11.05 Pv1 = 19.050.7025 = 27.13 W
  4. Подставляем в уравнение второй точки
    Pc = 11.05 − 0.25·27.13 = 4.27 W

c) График

Функции для построения: Ploss(x) = 4.27 + 27.13·x², а КПД считаем по формуле из листа (7.0.1), в ней уже стоят твои Pc и Pv1:

η(x) = x·Pnx·Pn + Pc + x²·Pv1

Потери при x = 0 равны Pc (4.3 W): машина ничего не делает, но греется. КПД при x = 0 равен нулю, потом быстро растёт, достигает максимума и медленно падает, потому что x²·Pv1 начинает кусаться.

d) Нагрузка с максимальным КПД

Откуда формула из листа: максимум η это минимум потерь на единицу полезной мощности, Ploss/x = Pc/x + x·Pv1. Производная по x равна −Pc/x² + Pv1 = 0, отсюда x² = Pc/Pv1. Смысл простой: КПД лучше всего там, где постоянные потери сравнялись с переменными.

xopt = √(4.2727.13) = 0.397 ηmax = x·Pnx·Pn + 2Pc = 95.1 % (в оптимуме x²Pv1 = Pc)
Ответ: a) x1 = 0.976, η1 = 93.2 %, Ploss1 = 30.1 W. b) Pc = 4.27 W, Pv1 = 27.13 W. d) xopt = 0.40 (ηmax ≈ 95.1 %).

Задача 1 · Червячная передача

ДаноЧервяк с z1 = 2 заходами вращает колесо с z2 = 36 зубьями. КПД передачи η = 72 %. Мотор крутит червяк n1 = 1200 RPM, момент на колесе M2 = 600 Nm.
  1. Найти i.
  2. Найти M2/M1 и момент на червяке M1.
  3. Найти n2, мощность мотора и мощность потерь.
Ответ

a) i = z2/z1 = 36/2 = 18.

b) M2/M1 = η·i = 0.72·18 = 12.96, M1 = 600/12.96 = 46.3 Nm.

c) n2 = 1200/18 = 66.7 RPM. ω1 = 2π·1200/60 = 125.66 rad/s, P1 = M1·ω1 = 5818 W ≈ 5.82 kW. Выход P2 = 600·6.981 = 4189 W, потери = 5818 − 4189 = 1629 W.

Задача 2 · Цикл работы станка

ДаноСтанок повторяет цикл T = 30 min. При работе (на полной нагрузке) Pin1 = 12 kW, η1 = 85 %. При смене заготовки Pin2 = 2 kW. Работа идёт 24 min, смена 6 min.
  1. Найти средний КПД и среднюю нагрузку за цикл.
  2. Сколько минут может длиться смена заготовки, чтобы средний КПД остался не ниже 80 %?
Ответ

a) Puseful1 = 0.85·12 = 10.2 kW. Wuseful = 10.2·24/60 = 4.08 kWh, Win = (12·24 + 2·6)/60 = 5.00 kWh. ηavg = 4.08/5.00 = 81.6 %. xavg = 24/30 = 0.80.

b) Разрешено на минуту работы: Pallowed = 10.2/0.8 = 12.75 kW. Бюджет на холостой ход: ΔP = 12.75 − 12 = 0.75 kW. t2/t1 = 0.75/2 = 0.375. t1 = 30/(1 + 0.375) = 21.82 min, поэтому смена до 8.2 min.

Чит-шит

Мощность и энергия

Pin = Puseful + Ploss P = M·ω · ω = 2π·n/60 W = P·t (P постоянная) Pin = U·I (мотор)

КПД и нагрузка

η = Puseful/Pin x = Puseful/Pn ηavg = Wuseful/Win xavg = Wuseful/Wnom

Потери

Ploss = Pc + xn·Pv1 η(x) = x·Pnx·Pn + Pc + xnPv1
  • n = 1 механика (шкивы)
  • n = 2 электрика (моторы)
  • n = 3 гидравлика (насосы, вентиляторы)

Оптимум по КПД

n = 2: xopt = √(PcPv1) n = 3: xopt = ∛(Pc2Pv1)
  • Общая формула: xn = Pc/((n−1)·Pv1)
  • n = 1: оптимума нет, η растёт до бесконечной нагрузки
  • В оптимуме переменные потери = постоянным при n = 2

Редуктор и червяк

i = ω1ω2 = z2z1 = n1n2 η = M2/M1i ⇒ M2 = η·i·M1
  • 1 = вход (ведущая), 2 = выход (ведомая)
  • У червяка z1 это число заходов, часто 1

Как решать, по шагам

  • Выпиши, что вход, что выход, что дано в W, kW, RPM, Nm.
  • Всё в СИ: kW → W, RPM → rad/s, % → доля.
  • Редуктор: найди i, потом моменты и мощности.
  • Цикл: ηavg = сумма Wuseful / сумма Winput. Если ищешь время: Puseful1/ηavg − Pin1 = бюджет на холостой ход, делишь на Pin2 → t2/t1, потом t1 = T/(1 + t2/t1).
  • Две точки измерения: два уравнения Ploss = Pc + x²Pv1, вычитай, чтобы убрать Pc.
  • Оптимум: формула для своей n.
  • Проверь: η меньше 1, потери положительные, Pin больше Puseful.

Где обычно косячат

  • Путают n в степени с n в RPM.
  • Забывают перевести RPM в рад/с (делить на 60, умножать на 2π).
  • Берут среднее арифметическое КПД вместо отношения энергий.
  • Оставляют проценты как 64 вместо 0.64.
  • Не вычитают m0 в балансирной установке.
  • Мешают kW и W, минуты и часы.
  • Берут Pn как входную, а она полезная.
